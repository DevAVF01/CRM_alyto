# Stellar Connector MCP

Conector oficial de integración con Stellar Testnet para **Alyto CRM** (AV Finance S.R.L. en el Entorno Controlado de Pruebas - ECP de ASFI).

## Capacidades
- Gestión y aprovisionamiento de **wallets custodiales** institucionales.
- Ejecución y trazabilidad de **transferencias internacionales**.
- Conciliación de hashes de transacción en Stellar Testnet Explorer.
- Gestión de comisiones y firmas corporativas seguras.
