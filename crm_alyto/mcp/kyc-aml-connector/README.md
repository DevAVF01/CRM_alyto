# KYC / AML Connector MCP

Conector especializado para debida diligencia de clientes institucionales y cumplimiento normativo en el **Entorno Controlado de Pruebas (ECP) de ASFI**.

## Capacidades
- Verificación en listas restrictivas internacionales (OFAC, Consejo de Seguridad ONU).
- Validación de NIT y Matrícula de Comercio SEPREC.
- Verificación de PEPs (Personas Expuestas Políticamente).
- Control del checklist de debida diligencia corporativa exigido por ASFI.
